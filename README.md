# Habit Tracker

Habit tracker personale, installabile su iPhone come web app.
I dati restano sul telefono; da Impostazioni si possono esportare e importare i backup, anche da HabitKit.

App: https://fzanetti-zzz.github.io/habit-tracker/

Icone: Tabler Icons (MIT). Font: Plus Jakarta Sans e JetBrains Mono (OFL).
